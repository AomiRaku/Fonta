# FontFox UI 规范

> 适用范围：FontFox 桌面端全部界面（Tauri + WebView2）。
> 本文与 `src/style.css` 一一对应；改样式前先改这里，避免出现"代码里能用、规范里没有"的野值。

---

## 0. 启动遮罩

- `index.html` 里 `#splash` 是 `position: fixed; inset: 0; z-index: 9999` 的纯色层，**关键样式内联在 `<head>`**（样式表还没加载时也要生效），浅色 `#f7f7f8`、深色 `#08090a`（`prefers-color-scheme` + `html[data-theme="dark"]` 两道）。
- 首屏渲染完成（`refresh()` 结束）后加 `is-hidden`，`opacity` 200ms 淡出，再移除节点；渲染失败也走 `finally`，另有 8s 兜底，避免一直白屏。

## 1. 设计语言：Flat

Flat 不是"没有设计"，而是**只保留结构与对比，不保留装饰**。具体约束：

| 项目 | 规则 |
| --- | --- |
| 阴影 | 不用于"浮起"效果。只有三处：菜单与 Toast 用 `--shadow-menu` / `--shadow-menu-soft`、行悬停用 `inset 0 0 0 999px var(--row-hover)` 叠底色；吸顶标题、按钮、对话框一律无阴影 |
| 渐变 | 禁止 |
| 高光 / 内阴影 / 3D 边框 | 禁止 |
| 圆角 | 控件统一 **2px**（按钮、输入框、开关、分段滑块、弹窗、Toast 等）；列表行与分组带仍为直角；窗口本身另由 DWM 提供系统圆角 |
| 侧栏宽 | **220px**（`--sidebar-w`），右侧 1px `--line` 分隔；标题栏横跨全宽 |
| 描边 | 组件默认**无描边**，靠底色区分；只有结构性分隔才用 1px `--line` |
| 分隔线 | 同一位置只允许一条线，禁止"两条 1px 叠成 2px" |
| 状态表达 | 用**底色**变化（hover / active / selected），不用缩放、不用阴影浮起 |
| 动效 | 只有功能控件（按钮、输入框、开关、分段滑块、选色点、弹窗标签）有过渡：**50ms**；输入框聚焦下划线 **100ms**；开关滑块 **200ms**。菜单、列表行、侧栏项一律**即时切换**，不做过渡。菜单出现/消失 50ms 纯渐变、无位移 |

保留的少量"线"只有四类：工具栏底边、表头底边、家族首行顶边、详情面板左边。

### 2.5 字体

- 界面：`system-ui, -apple-system, "Segoe UI", sans-serif`
- 等宽：`ui-monospace, "Cascadia Code", Consolas, monospace`（文件路径、注册表）
- **不打包任何字体文件**；预览字形由 Rust 栅格化。字体里没有的字符**直接不显示**（不做字形回退），所以英文字体预览中文时只出现拉丁部分；**默认预览文字**在字体里一个字形都没有时，自动改用字体自身 cmap 里的字符取样（最多 24 个），符号 / 图标字体因此能显示图标；**用户手动输入**的预览文字缺字时不做替换，行与详情都显示「预览文字没有对应字符」（13px、`--muted`）。

## 3. 布局与对齐

竖向：标题栏 40 → 工具栏 48 → 表头 28 → 列表（分组带 28 / 紧凑行 38 / 预览行 76）；左右外边距 16px。
横向：侧栏 220px（固定）→ 主列（标题栏与工具栏）→ 详情面板 300px（固定，可收起）。

规则：

1. **左右外边距恒为 16px**：标题栏、工具栏、表头、列表行、分组带、详情面板全部对齐同一条竖线。
2. 标题栏右侧窗口按钮组距右边缘 4px（等于其上下留白），与原生圆角留出安全距离。
3. 表头列宽与行共用 `--cols-compact` / `--cols-preview`，永远不要在两处各写一遍。
4. 名称列左侧留 16px 缩进（表头、分组标题、行内名称共用同一基线），文字统一从 32px 起。
5. 元素间距只用 4 / 8 / 12 / 16；同一行内控件之间的间距统一 8px。
6. 竖向节奏：标题栏 40 → 工具栏 48 → 表头 28 → 行 38（预览 76）→ 底边。

## 4. 组件规范

### 4.0 侧栏

- 宽 `--sidebar-w` 220px；左上角品牌区高 88px（40 + `--toolbar-h`），内联 SVG Logo 宽 122px（高约 27px）、垂直居中并左对齐（左边距 `--sp-3` + 4px）（深色模式只切换文字色），导航首项与列表表头同高；导航区左 / 右 / 下内边距 `--sp-3`（12px），顶部为 0，导航项 36px，字体单条目 32px。
- 导航顺序：全部字体 / 收藏字体 / **已停用** / **缺失字体** / 字体单区 / 更多。每一项右侧显示数量（界面字体、`--fs-sm`、`--muted`，不用等宽字体）；**缺失字体为 0 时整项隐藏**。
- **已停用**：列出所有处于停用状态的字体，计数与空态跟随该视图（计数只统计当前视图范围）。
- **字体单区**：标题「字体单」+ 右侧 `+`（与标题同为 `--muted`）；没有字体单时标题下方居中显示 12px `--muted`（60% 不透明度）的「还未创建字体单」。条目整体比导航项右移 1px（`padding-left: 9px`），视觉上与上面的图标列对齐，里面画一个**外径 12px、描边 3px** 的空心圆环作为标记色。
- 标记色共 10 种：`E21414 EB6B26 FFC300 B4D400 23C22D 22B7AB 0FC3E7 0084FF 9239FF FFC9`——新建时随机取一个当前未使用的颜色，老数据没有颜色时按序号分配。
- 字体单上限 **20** 个；新建后进入就地重命名——**只把名称文字换成输入框，标记环保留原位**，字号 13px 与常态一致（输入框 `--bg-raised` 底 + 1px `--line-strong` 内描边，高 22px）；Enter 提交、Esc 取消。右键菜单为「编辑 / 删除」。
- **编辑**：弹出「编辑字体单」对话框——标记色环（10 选 1，选中项外圈加粗）+ 名称输入框，底部「取消（浅灰实底）/ 好（深色实底）」；回车即保存。 字段标题用 `span`（不是 `<label>`），点标题文字不会聚焦输入框；输入框通过 `aria-labelledby` 关联标题。
- 底部**更多**按钮（三道杠图标）向上弹出**专用菜单**（`.more-menu`）：宽 196px、条目 34px、字号 **14px**，圆角 2px、1px `--popover-line` 描边、轻阴影，**无任何动画**；菜单打开期间「更多」按钮保持激活底色（`.sidebar__item.is-open`）；条目依次为「重新扫描字体 / 设置 / 检查更新（置灰）/ 关于」。
- 条目：高 36px、左右 8px 内边距、图标 16px，圆角 2px，**文字 14px**（比字体单名称大一号）；字体单条目高 32px、无图标、左内边距 9px，名称 13px。三档状态：悬停 `--side-hover` → 选中 `--side-selected`（文字 `--ink`，不加粗）→ 按下 `--side-press`（只比选中略深）。右键命中的条目用 `.is-ctx` 保持选中底色。右侧数量统一 13px `--muted`。
### 4.1 标题栏（自绘，仅主列）

- 高度 40px，**只占主列宽度**（右侧放窗口按钮）；无系统标题栏（`decorations: false`）。窗口**不透明**（`backgroundColor: #F7F7F8`、`shadow: true`）：4px 圆角（`DWMWCP_ROUNDSMALL`）、描边、阴影与窗口动画全部由 DWM 提供，页面不画窗口外壳；最大化时由 DWM 铺满。
- 右：主题切换 → 分隔线（1×16px）→ 最小化 / 最大化 / 关闭。
- 主题三态：**跟随系统（默认）→ 浅色 → 深色**，初始值 `system`（写 `config.ini` 的 `Theme`）；`:root` 是浅色令牌，深色由 `html[data-theme="dark"]` 覆盖，截图与规范以浅色为准。按钮图标随状态切换（显示器 / 太阳 / 月亮）。
- 窗口按钮 32×32，图标 15px（iX 图标字形占比偏大，统一 15px 即可视觉等重），**无边框**；关闭键悬停 `--close` 底 + `--on-close` 图标。 **窗口失焦时**主题按钮与三个窗口按钮整体降到 45% 不透明度（120ms 过渡），重新获得焦点恢复。

### 4.2 工具栏

- 高度 48px，底边 1px `--line`。
- 搜索框：宽 260（可缩到 140）、高 32，圆角 2，底色 `--control-bg`，无描边，左侧 14px 图标；聚焦时底部 3px 粗线自左展开。**有内容时右端出现 18×18 的清空按钮**（12px 叉、悬停加底），点击清空并保持聚焦；输入框右侧固定留 26px。
- 分段控件：两格等宽且为**正方形**（`width: var(--control-h)` = 32px），纯图标（紧凑 `table-rows`、预览 `text-alginment-justified`，15px），`title`/`aria-label` 提供文字；高亮块四周内缩 3px（26×26），切换时整格平移。
- 预览文本框 200px（可缩到 120px），右端与详情面板内容右边界对齐（窗口右侧 - 16px）；留空显示灰色占位「输入文字预览」。**有内容时同样在右端出现清空按钮**（同一套 `.field__clear`）。**预览字号固定 24px**。**预览文字不持久化**：启动时输入框为空，使用默认预览文字。 预览框右侧是详情面板开关（32×32 图标按钮，与筛选按钮同款）：展开时 `navigation-right-hide`、收起时 `navigation-right`。
- 筛选按钮（`filter`）、分组按钮（`group`）、详情开关（`detail-toggle`）均为 32×32 图标按钮，位于搜索框右侧；网格图标为 16px。
- 元素顺序固定：搜索 → 筛选 → 弹簧 → **分组** → 视图切换 → 预览文本（贴右）。分组按钮在未分组时是 32×32 图标按钮（`list-graphics-text`，14→16px）；选中任一分组依据后变宽显示当前依据名称，并保持 `is-active` 底色（与筛选激活一致）。

### 4.2.1 筛选菜单

- 点「筛选」按钮在按钮下方左对齐弹出：左侧分类 tab、右侧选项列，列间 1px `--line` 分隔。面板不描边，`--bg-raised` 底 + `--shadow-menu`；出现 / 消失 **50ms 纯渐变、无位移**。整块最大高度 = 8 个 tab（`--fmenu-tab-h` 34px），超出时两列各自滚动；滚动条为悬浮样式且**常驻**（`setPinned(true)`），`z-index` 取宿主浮层 +1（菜单 900 → 901），轨道上下内缩 4px（`setInset(4)`）；两列都设 `min-height: 0`，保证在高度上限内真正产生内部滚动。
- 选中 tab：文字 `--ink` + 600，左侧 3px `--brand` 竖条；hover 叠 `--row-hover`。tab 右侧显示该分类**已选项数**（18px 方块、`--control-bg-hover` 底、11px/600 `--ink-soft`、2px 圆角），为 0 时不显示。选项行 30px，已勾选项左侧显示 16px 对勾并加深文字。
- 选项即时生效（多选，同组内为「或」、组间为「且」）。样式按**家族**判定：命中就把整个家族算进结果。
- 菜单打开时筛选按钮与分组按钮都保持 `is-open` 底色（`--control-bg-hover`，压过 hover / active），**与是否已激活筛选 / 分组无关**；有任何筛选条件时图标换成 `filter-filled`，按钮变宽并在右侧显示「已筛选出 N 项」，左内边距固定 9px 保证图标与窄态同一竖线。左侧分类列底部固定一个 **「清除筛选」** 按钮（高 32px、左右内边距 8px；有任意勾选时可用，无勾选时置灰禁用）；点击清空全部分类并立即重绘列表。
- 关闭方式：再次点按钮、点击菜单外、Esc。
### 4.2.2 分组菜单

- 点分组按钮弹出单列菜单，宽度 168px，行高 32px，左侧 14px 勾选位（选中项显示 `check` 图标），选中项文字 `--ink`、未选中 `--ink-soft`；悬停 `--control-bg-hover`。

### 4.4 列表行
- 切换紧凑 / 预览：行高不同会导致阅读位置偏移，所以切换前先记一个「锚点行」——**选中项在视口内**就用它（字族行或字体行），否则取**视口中线所在行**；重建后把该行滚到视口正中（`list.centerKey`，结果夹在 `[0, total − 视口高]`）。查找是 `indexOf` + 二分，只有一次滚动赋值，无额外渲染开销。切换前若已在列表**顶部或底部**（1px 容差），重建后直接回到顶部 / 底部，不再按锚点居中。

- 紧凑 38px，预览 76px；左右内边距 16px。
- **不画任何行分隔线**：相邻行靠 A/B 交替底色（`--row-alt`）区分；**字族标题行与族内字体行都参与交替**，分组标题不参与（每组从白色重新开始），保证整列严格一深一浅。
- 悬停是**叠加**（`box-shadow: inset 0 0 0 999px var(--row-hover)`），不替换底色，A/B 交替行色始终可见；选中替换为 `--row-selected` 并清掉叠加。**行的悬停 / 选中不做渐变**（`.row { transition: none }`）；**选中行不吃悬停**（`.row--selected:hover` 同色），否则点击后会闪。字族不做「整组变色」：悬停与选中只作用于当前这一行。
- 按启用状态分组时，同一字族可能同时出现在多个分组：每个分组只显示属于该组的样式，行 key 带分组作用域，互不影响展开、选中与详情。
- 同字族（≥2 个样式）默认折叠成一条**字族行**（38px）：家族名与普通行左边界对齐（文字 x = 32px = 行内边距 16 + 名称格内边距 16）。名称后接一个**灰底标签**（高 20px、圆角 2px、**半透明叠加底色 `--row-hover`**（悬停 `--row-selected`，这样在普通行与选中行上都拉得开对比）、12px `--ink-soft` 文字），内容为「N 个样式」+ 右侧 12px 箭头；**标签整块可点，点击展开 / 收起字族**，箭头播放 160ms 旋转（展开 0°、收起 -90° 指向右），只在点击切换的那次重建里播放，滚动重建不重播。**字族行最左边不再有折叠箭头**，选中竖块仍居中于左侧留白（x = 16px）。折叠时右侧显示语言、总大小、总控开关，展开时这三格只留总控开关；展开 / 收起时语言、总大小与预览示例播放 160ms 渐隐下移 / 渐显上移动画（只在点击切换的那次重建里播放）；**整族都受保护 / 文件缺失时该格显示 14px 锁图标**，不出现开关。
- 双击普通字体行：详情面板收起时打开详情，不改变当前选中项。
- 字族标题行：单击**只选中**；双击的含义取决于详情栏——**详情栏收起时双击先打开详情（选中并查看），不展开字族**；详情栏已展开时双击才展开 / 收起字族。选中态在渲染时动态读取，滚动重建后不丢失。连击用 `click.detail` 判断：连续两次双击（detail 2、4）都能依次展开 / 收起，不会因浏览器只派发一次 `dblclick` 而失效。
- 选中行左侧 6×20px **品牌色**竖块（`--brand`，距行首 13px），`pointer-events: none`，点击标记位置会落到行左侧选中槽，因此点已选中的标记即可取消选中；悬停该位置时竖块变为略深的 `--brand-deep`。
- 已收藏字体在竖块中心叠一个 **6×6** 的 `--favorite` 方块，用 `z-index: 1` 保证在选中竖块上层；未选中时同样显示（与选中态无关）。整族都被收藏时字族标题也显示该方块：收起时不透明，展开时降到 25%（与选中竖块一致）。
- Shift 范围选择的基准是上一次点击的行（锚点），范围限定在当前可见顺序内。
- 受保护字体的锁图标放在「启用状态」列（开关位置），语义即"此处不可操作"。
- **可变字体**的行样式与详情副标题统一显示「可变字体」，不显示 name 表里的最小字重档位名（如 Thin）；预览按 `wght = 400` 渲染，若 400 不在可变范围内则取范围中点。
- 预览行：左列（家族 + 样式 + 标签）；右列显示被预览字体自身渲染的文本（位图），纵向居中、单行排布，超出列宽的部分用**右侧渐变淡出**（约 28px）而不是硬截断；行内不叠加操作按钮。点阵字体（`.fon` / `.fnt`）不渲染位图，右侧显示 13px `--muted` 的「系统点阵字体无法预览」。预览位图按当前主题的正文色渲染；切换主题时自动清空位图缓存并重绘，不需要重新选中字体。
- 行内只有一个启用开关（受保护时换成锁图标、文件缺失时显示「—」）；停用、删除、清理残留都在详情面板或右键菜单完成，行内不放操作按钮。
- 虚拟滚动只渲染视口内的行，上下各多 2 行缓冲，兼顾流畅与开销。
- 空态：标题上方居中显示 **180×180** 插图（几何取自 `src-tauri/img/EmptyL.svg`，浅 / 深共用一份内联 SVG，`fill` 跟随 `--ink`），整体 **30% 不透明度**；标题用 `--fs-base`、提示用 `--fs-sm`，均为默认界面字体（不用等宽字体）；两行间距 `--sp-1`（4px）；扫描中隐藏插图。空态文案按视图区分：收藏、已停用、字体单、缺失、搜索无匹配各有独立标题与提示。
- **多选**：点击单选，Ctrl / Shift 点击增减或按锚点做范围选择；每行最左侧的选中槽（约 27px 宽，`z-index: 2` 位于收藏方块与选中竖块之上）点击按多选切换，悬停时在该位置显示 10% 不透明度的品牌色标记；表头左侧同宽的选中槽点击可全选当前列表、已全选时清空，全选时槽内显示与选中标记同宽的 6×6 方块，悬停时方块颜色变为略深的 `--brand-deep`，未全选时悬停显示同形状的 10% 透明方块；选中项以 `.row--selected` 标记，左侧品牌色竖块逐行显示。**字族行与字体行都是可选中单元**：Ctrl 点击在两者间增减；Shift 范围按行顺序覆盖途经的字族（折叠字族整体参与，展开时按子行参与）；如果范围终点落在某个字族的子行上（没有完整覆盖该字族），会跳过这个字族的标题，只选范围内的子行。选中一个字族的全部字体即视为选中该字族（字族行与展开后的子行同时显示选中，展开时字族标题的选中竖块降到 25% 不透明度）；只选中一个完整字族时右侧显示字族详情，族内只选中部分字体时字族行自动取消选中。选中 ≥2 个字体时详情面板切换为批量视图：标题「已选择 N 个字体」+ 说明行 + 操作按钮（停用 / 启用按钮横向撑满剩余宽度，删除在行尾），**不显示字体清单**；**反向选择**独占上方一整行（按当前筛选结果反选），停用 / 启用与删除在它下面一行。

### 4.6 分组标题

- 整行 **28px**（`--group-h`），**满宽实色带**（`--group-bg`：浅色 `#e9e9ea` / 深色 `#191a1b`，不要用半透明，否则吸顶时下方内容会透出来），把一组内容整体框住；除首个分组外，色带顶部压一条 1px `--line` 细线，收住上一组。
- 左侧放**加号 / 减号**（`.group__sign`，10×10、所在行左内边距 11px 使其中心落在 16px 轴线；横竖各一条 **9×2.5px** 圆角线，颜色 `--ink`（随主题），**常态 62% 不透明度**，鼠标悬停整条分组标题时恢复 100%）：收起时是 `+`；展开时**两条线一起绕中心转 90°**，同时**横线淡出**，转过来的竖线成为唯一的横线（`−`）。全程只旋转 + 透明度，不缩放，所以不会变形；切换 160ms ease-out，只在点击展开/收起时播放（滚动重建不重播）。后接 **12px/500** `--ink-soft` 标签（不加粗）+ 11px `--muted` 计数。
- 分组标题**不画右侧横线**：分组之间靠色带与顶部细线区分。
- 吸顶副本与列表内同宽同高（`left/right = 0`、高 28px = `--group-h`），底色同样用 `--group-bg`，交接没有几何跳变。
- 吸顶时直接贴住上、左、右三边（无过渡动画）；下一个分组标题逼近时被向上顶出（`translateY ∈ [-28, 0]`），容器 `overflow: hidden` 负责裁切。 吸顶标题复用同一个 `.group__sign` 加号 / 减号，展开状态**每次滚动都同步**（在吸顶状态下直接点击也能正确切换）。
- 吸顶不加阴影。搜索时强制展开所有分组。
### 4.7 详情面板
- 详情面板固定 300px；标题 / 样字 / 操作区固定，只有从「字体信息」开始的元信息区独立滚动（`overflow-y: auto`），滚动条用悬浮样式（见 4.11）。**可收起**：默认展开，状态存 `config.ini` 的 `DetailOpen`；收起时面板保持 300px 宽度，靠 `margin-right: -300px` 让出布局空间，整块向右平移并淡出（内容宽度不变，不会被挤压重排），**160ms `cubic-bezier(.2,0,0,1)` 过渡**，列表跟着平滑变宽；`prefers-reduced-motion` 下不做动画。工具栏预览框右侧有同款 32×32 图标按钮切换，展开时图标 `navigation-right-hide`、收起时 `navigation-right`。
- 宽 300px（固定，不随窗口变化），内边距 16px，左边 1px `--line`。
- 标题 19px（`--fs-title`）/ 600；下方仅副标题（样式），不显示作用域。**副标题行固定 `min-height: 17px`**——像 `Courier 10,12,15` 这种没有样式名的字体也占一行，避免下方内容上移。
- 无选中时只在面板内**垂直+水平居中**显示一行「选中字体查看详情」，不再有标题行。
- 分区顺序：字体信息（常驻） → 「其他信息」折叠区（文件 + 注册表，默认收起）。
- 样例区：**4:3 固定比例**，底色 `--bg-raised`，无描边，内边距 16px；样字是 Rust 栅格化的位图，按面板宽度**自动折行**（最多 8 行），字号固定 28px，不缩字。
- 操作区：实心按钮高 32px（`--control-h`），底色 `--bg-active`；危险按钮 `--danger-weak` 底 + `--danger` 字。**整行固定 `min-height: var(--control-h)`（32px）**——受保护字体没有按钮时也占同高度，避免下方信息区上移。
- **可变字体**：操作区下方增加一行「字重」滑块（`input[type=range]`，范围取该字体 `wght` 轴的实际最小/最大值，步进 1）+ 当前数值。拖动时实时重绘样例区，**不持久化**；松手后最终字重写入缓存。非可变字体、或没有 `wght` 轴的字体不显示这一行。
- 删除只通过**模态确认框**完成（见 §4.8），面板内没有就地二次确认。
- 元信息按「文件 / 字体信息」分组：右侧值（`.kv__v`）允许拖动选中复制，其余详情文本不可选中；组标题 14px / 常规字重、`--ink-soft`，左侧一个 3×14px 的 `--ink` 长矩形，不画分割线；键列固定 72px（12px `--muted`），值列等宽字体。**语言**一行常驻：判不出语言（符号 / 图标字体）时显示「未知」，与列表列一致。
- 注册表等技术信息默认收起，由「更多信息」展开。
- **字族详情**（选中的正好是某个字族的全部字体时）：标题为家族名、右侧带一枚「字族」标签（`.tag`，18px 灰底 `--row-hover`、`--muted` 文字、600 字重）、副标题“N 个样式”；预览块用首个字重，并在背后叠两层 `--bg-raised` + 1px `--line` 的“牌”，向右下各偏移 5 / 10px，暗示这是一个字族；操作区只有停用/启用与删除，没有「打开文件位置」；信息区只有字族名称、版本、版权，不显示文件与注册表。预览模式下也用首个字重。 **整族受保护时**：停用/启用按钮不出现，原位置显示 11px `--muted` 的「受保护的系统字体」，只保留「打开文件位置」。
- **受保护字体**（单个）：停用按钮位置显示同样一行「受保护的系统字体」，不提供删除，提供「打开文件位置」。系统字体位于 `C:\Windows\Fonts`（Shell 虚拟文件夹），路径无法被 `ILCreateFromPathW` 解析，所以「打开文件位置」打开「字体」文件夹（`shell:Fonts`）；其余位置（含用户字体目录）用 `SHOpenFolderAndSelectItems` 精确选中文件。

### 4.7.1 收藏与字体单（持久化）

- 数据存 `%USERPROFILE%\.FontFox\library.json`：`{ favorites: string[], collections: [{ id, name, fonts: string[] }] }`。
- 字体用稳定 id（`{scope}:{valueName 小写}`）引用，扫描结果变化不影响已收藏/已加入的条目；不存在的 id 会自动被忽略。
- 写入走「临时文件 + rename」，损坏的文件改名成 `library.json.broken` 后按空库启动。
- 侧栏改动（新建 / 重命名 / 删除字体单、收藏）在 250ms 防抖后整体保存。

### 4.8 对话框（关于 / 许可 / 删除确认）

- 遮罩 `--overlay`（浅色 黑 42%、深色 黑 62%），面板 `--bg-raised` + 1px `--popover-line`，**2px 圆角、无阴影、无内部分割线**。入场 / 退场：面板与遮罩**同步 100ms 淡变，没有位移**；**点击背景不关闭**，只能点 × / 取消 / 按 Esc。

- 正文：上 **16px**、左右 **24px**、下 **20px**；底部操作条左右 24px、上下 20px，按钮右对齐、**34px 高 / 14px 字号 / 左右 18px 内边距 / 最小宽度 67px**（两个汉字 + 3px 余量，单字按钮同宽）。按钮三种语义：**一般**（`--control-bg`，悬停 `--control-bg-hover`、按下 `--control-bg-active`，如「取消」）、**高亮**（`--ink` 实底，如「好」）、**危险**（常态无底红字，悬停 `--danger-weak`，按下同底更淡，如「删除」）。
- 关闭方式：关于框可用 × 或 Esc；删除确认框只有「取消 / 删除」或 Esc；**所有对话框都不响应点击背景**。

### 4.8.1 设置窗口

- 普通模态：宽 440px，标题「设置」，右上角 ×，Esc 可关；**切换进行中禁用关闭**（× 与 Esc 都忽略）。
- 正文一项：「字体禁用方式」下拉（Windows 基础模式 / 动态安装卸载模式）+ 两行说明文字（13px `--muted`）。

- 迁移逻辑：先在旧模式下恢复全部禁用字体，写入新方式，再在新模式下按原集合重新禁用；失败数量通过 toast 提示。

### 4.8.2 禁用文件对账弹窗

启动时把禁用清单（`disabled.json`）与隔离目录对一遍，两种情况各弹一次：

- **目录里多出文件**：标题「发现未登记的禁用字体」，正文「隔离目录里有 N 个文件不在禁用清单中，是否把它们添加到字体列表？」，名单显示解析出的家族名与文件名；按钮 `[稍后处理] [添加到列表]`。
- **清单里文件丢失**：标题「已禁用字体缺少文件」，正文「清单中有 N 个字体在隔离目录里找不到文件，是否从清单中移除？」，名单显示家族名与样式；按钮 `[稍后处理] [删除记录]`（`btn--ghost-danger`）。
- 两个弹窗都可 Esc / 点 × 关闭（等同「稍后处理」，下次启动再提示），确认后立即重扫列表。

### 4.9 Toast

- 位置固定在**右上角**：`top = 标题栏 40 + 工具栏 48 + 4 = 92`，右内边距 16px，右端与详情内容右边界对齐。
- 单条最大宽度 **380px**，超出自动换行（`overflow-wrap: anywhere`）。
- 字号 **13px**（`--fs-sm`）、**字重 600**：普通提示 `--ink-soft`，危险提示文字转 `--danger`；与菜单同一套浮层样式：边框 `1px solid var(--popover-line)`、阴影 `--shadow-menu`、圆角 `var(--radius)`。
- 入场：从右侧 16px 滑入 + 淡入，180ms ease-out；退场：只淡出 150ms，**不做位移**。
- 新提示插到最上层，旧提示整体下移 180ms 平滑过渡（FLIP + transform），各自计时淡出（普通 3.6s、危险 6.5s）。

### 4.9.1 右键菜单

- 自绘菜单：`--bg-raised` 底 + 1px `--popover-line` 边框、2px 圆角、`--shadow-menu`；出现 / 消失为 **50ms 纯透明度渐变、不做位移**。
- **右键选择规则**：普通状态下右键直接选中命中的行（替换之前的选择）再弹菜单；多选状态下右键**已选中**的行保留多选，菜单作用于全部选中项，并在顶部加一行 12px `--muted` 的「N 个项目」（按字体数量计）；多选状态下右键**未选中**的行会清空多选，只选中该项。字族行与字体行一样是选中单元：右键未选中的字族行只选中整族，右键已选中的字族行同样作用于全部选中项；右键字族行时菜单顶部始终显示该字族的字体数量（如「9 个项目」）。菜单关闭后不保留额外的"右键命中"底色。
- 菜单项 32px 高、左右 16px 内边距、**13px**（`--fs-sm`）；悬停 `--control-bg-hover`；禁用项 50% 不透明度 + `--muted`；危险项 `--danger` 字，悬停 `--danger-weak` 底。
- 带二级菜单的项右侧显示 `›`，悬停向右展开（右侧放不下则翻到左边）。
- **输入框**（搜索 / 预览文本）：复制 / 粘贴 / 剪切；无选中时复制与剪切置灰。
- **字体行**：
  - 全部字体：启用（禁用）/ 收藏（取消收藏）/ 添加到字体单 ›（列出全部字体单，已加入的置灰）；
  - 收藏字体：启用（禁用）/ 取消收藏；
  - 某个字体单：启用（禁用）/ 从字体单移除。
- **字体单条目**：重命名（就地编辑，Enter 提交、Esc 取消）/ 删除（危险，走确认弹窗）。
- 点击外部、Esc、滚动、窗口失焦都会关闭（二级菜单属于同一组，命中它不会误关）；越界时自动向内收，保证完整可见。
- 剪贴板读写走 Rust 侧插件（`tauri-plugin-clipboard-manager`），**不使用 `navigator.clipboard`**，因此不会触发 WebView 的权限弹窗。

### 4.10 启用状态开关 / 语言列 / 排序

- 启用状态用开关表达（`.switch`）：轨道 **30×16**、圆角 **2px**，滑块 **9×12**、四周内缩 **2px**，横向位移 17px，200ms 过渡；**悬停时滑块 `scale(1.14)`**——位移与缩放在同一个 `transform` 里（`translateX(17px) scale(1.14)`），缩放中心就是滑块自身中心，200ms 过渡；等待后台写入的禁用态仍保留缩放，避免开关尺寸跳动。**开 = 深色轨道 `#1E1E1E` + 浅色滑块 `#E3E3E3`（右）**；关 = 半透明轨道 `rgba(0,0,0,.10)` + 中灰滑块 `#808080`（左）。禁用：开 `#A7A7A7` / 关 `rgba(0,0,0,.06)` 轨道，滑块统一 `#D4D4D4`，不响应悬停。深色主题：开 `#E6E7E8` 轨道 + `#1A1B1D` 滑块，关 `rgba(255,255,255,.2)` 轨道 + `#8B8F96` 滑块，禁用轨道 `.08` / `#4B4E53`、滑块 `#9AA0A6`。
- 紧凑与预览模式都常驻显示开关；受保护字体在开关位置显示**锁图标**，表示不可修改。预览行的名称不显示作用域/状态标签。 开关**本地先行**：点击立刻切换状态并重绘（0–1ms），写注册表在后台完成；点击后开关进入禁用态（保留新位置、禁用样式），直到后台写入完成且至少保持 800ms 禁用（避免后台过快导致看不出禁用而被连续点击），期间不能再次点击；开关右侧空白处显示旋转加载圈（开关本体保持禁用灰态，滑块不隐藏），加载圈出现 / 消失均为 150ms 透明度过渡；成功 / 失败的 Toast 在开关恢复可点之后才弹出。Windows 基础模式按单个样式启停：同族样式可以分别处于启用 / 停用状态；按启用状态分组时，字族会随成员状态拆成多行，每行只包含该组样式；快速连点按条目版本裁决，旧请求不会覆盖新状态。
- 所有控件**都不显示键盘焦点描边**（全局 `:focus-visible { outline: none }`）；输入框仍有聚焦下划线这一视觉反馈。
- 语言列显示**主语言**：按字形覆盖判定（每种语言定义一组必需字符，cmap 全部覆盖才算支持），中文 / 日文 / 韩文 / 英语 / 德语 / 法语 …；详情面板的「语言」一行列出全部命中的语言，用「、」分隔。覆盖率不足时退回 name 表的书写系统启发（拉丁文 / 西里尔文 …），不再出现「多语言」。
- 可排序表头：`字体名称`（**符号 → 数字 → 英文 → 拼音（汉字） → 其他文字**，同类内再按字母/拼音比较，数字按数值大小）、`状态`（已启用在前）、`语言`（按语言分组）、`大小`（按字节数）——四列首次点击为默认顺序，再次点击切换正/倒序；同值一律按名称排序。
- 激活的排序列在文字后显示 **6×5 的实心小三角**（顺序向上、倒序向下），距文字 5px、整体上移 1px 与文字中线对齐，颜色 `--muted`。

### 4.11 分组展开动画与滚动条

- 展开/收起**列表本身无动画**（点击即时切换）；只有三角播放 160ms 旋转。搜索时查询变化会自动展开全部分组，之后仍可正常点击收起。
- 整条标题（三角、文字、横线）是**同一个 hover 整体**：悬停时三角与横线一起加深到 `--family-line`，标签与计数恢复不透明；点击区覆盖整行，光标为手型。
- **悬浮滚动条**（`src/scrollbar.ts` + `.ovl-scroll`）：原生滚动条隐藏且不占轨道（`scrollbar-width: none` + `::-webkit-scrollbar { width: 0 }`，不使用 `scrollbar-gutter`，表头不留补偿位），滚动时在内容右侧浮出一个 **6px 宽、1px 圆角**的长条，颜色取 `--ovl-thumb`，拖动时取 `--ovl-thumb-hover`。悬停容器或滚动时显示，静止 700ms 淡出；支持拖动滑块。叠加层始终位于列表吸顶分组标题之上（计算层级下限为 10）。列表、详情面板的元信息区、字体单列表、筛选菜单、弹窗正文都走这一套；弹窗与菜单关闭时销毁叠加层，避免节点堆积。

## 5. 控件状态（统一）

- **光标约定**：列表行、分组标题、侧栏 tab、字体单、菜单项一律用箭头（`cursor: default`），只有按钮、图标按钮、开关、输入框清空叉、**字族的「N 个样式」标签**用手型——桌面应用的惯例，手型只代表「可点的独立控件」。


所有按钮、输入框、开关、分段滑块、下拉菜单共用同一套状态梯度：**常规可见 → 悬停更强 → 按下介于两者之间**，任何控件都不允许"悬停反而变淡"。

| 状态 | 底色 | 文字 |
| --- | --- | --- |
| 常规 | `--control-bg` | `--ink-soft`（次要控件可用 `--muted`） |
| 悬停 | `--control-bg-hover`（更明显） | `--ink`；过渡统一 50ms ease-out |
| 按下 | `--control-bg-active`（比悬停弱、比常规强） | `--ink` |
| 焦点（输入框） | 底部 3px 粗线自左向右展开（100ms，cubic-bezier(.2,.8,.2,1)），失焦按原路收回 | `--ink` |
| 选中 / 当前 | 分段控件用滑块 `--ink` 反色 | `--bg` |
| 禁用 | `opacity: 0.5` | 同上 |

- 输入态**不描边**：底部粗线用 `linear-gradient` 背景 + `background-size` 从 `0%` 到 `100%` 实现（100ms 缓动展开、失焦反收），不占布局，文字始终在垂直中线上。
- 聚焦后**忽略悬停/按下**的背景变化（`:hover:not(:focus)`），避免鼠标划过时底色抖动或把底部线重置掉。
- 控件高度：`--control-h: 32px`（搜索框、输入框、下拉、分段控件、图标按钮、实心按钮）。

### 5.1 其它状态

| 状态 | 表达方式 |
| --- | --- |
| 键盘焦点（非输入控件） | 无外轮廓（`:focus-visible { outline: none }`） |
| 危险 | `--danger` 文字；悬停 `--danger-weak` |
| 加载 | 图标旋转 + 按钮禁用；列表空态显示「正在扫描…」 |

## 6. 文案规范

- 全中文；产品名统一 "FontFox"。

## 7. 无障碍与键盘

- 所有图标按钮必须带 `title` 与 `aria-label`；分段按钮用 `aria-pressed`，标签页用 `aria-selected`，分组用 `aria-expanded`。
- 顶部窗口按钮可 Tab 到达；关闭键不是默认聚焦项。
- 列表：↑/↓ 移动选择；点击单选，Ctrl 点击增减，Shift 点击按锚点做范围选择；Esc 取消选择、再清空搜索；**Ctrl+A 全选当前列表**：在任何位置都阻止浏览器全选界面文字（输入框内只选中输入内容），**Delete 等同删除按钮**（打开删除确认，仅针对可删除的选中字体）。有模态弹窗打开时这两个快捷键不生效；焦点在输入框 / 文本域时也不接管。
- 界面文字默认不可拖动选中（`user-select: none`）；仅字体信息右侧值、NOTICE / 许可证正文、输入控件允许选中；可选中文字不能被拖放，选中文字后右键弹出「复制」菜单；没有选中文字时不弹菜单。
- 颜色不作为唯一信息载体：受保护字体用锁图标代替开关，表示启用状态不可修改。

1. 控件圆角是否统一为 2px？有没有多余的阴影/渐变？

10. 新增文案是否已加入本文档的「文案规范」或对应组件条目？
